## Композиция

Сохранены направляющая 1312 px, шапка, футер, Montserrat/Source Sans 3, navy и янтарные акценты. Общая страница: hero → каталог → тарифы → условия → две услуги → контакты. Страницы техники: hero → варианты → применение и подбор → условия → связанные направления → контакты; у кранов и экскаваторов есть предметный FAQ. Для услуг без машин фотокаталог не имитируется.

Новые секции `rentalCatalog`, `equipmentCatalog`, `rentalRates` зарегистрированы рядом с существующими секциями, используют единый каталог и собственные классы в `internal-pages.css`. Карточки категорий имеют 3/2/1 колонки, оборудование — 2/1, одиночная машина — split на широком экране. Характеристики размечены dl, тарифы — table с заголовками и ссылками на конкретную машину. Все функции доступны без JavaScript, кроме общей навигации; ссылки и контент статичны.

Основной CTA — звонок +7 (922) 448-88-22. WhatsApp берётся из существующего contact-details.json. PageDefinition.mobileCallbar меняет подписи только для аренды. Форм и калькулятора нет. `rental: true` включает тематическую оболочку и отдельный critical CSS, не новое семейство страниц.

## Проверки и сопровождение

`npm run verify` включает проверку состава каталога, тарифов и связей. Browser runner проверяет все страницы аренды на 11 контрольных ширинах, клавиатуру FAQ, цели 44 px, цены, фото и переходы. Существующий полный прогон сохраняет регрессии прежних страниц. Lighthouse использует прежний порог 95.

Обновление фотографий: `node tools/prepare-rental-media.js`. При изменении старого каталога скрипт останавливается, если число карточек отличается; соответствие фото и машин нужно проверить перед запуском. Он использует Sharp и оригиналы сайта; Windows fallback читает настроенный системный proxy через Invoke-WebRequest.

Critical CSS: `npm run build`, `npm run generate:critical`, `npm run verify`. Перед коммитом dist должен оставаться preview с noindex и без sitemap. Внешний домен не переключается автоматически.

## Изображения первого экрана — 30.09.2026

Все 12 страниц аренды используют новый декоративный кадр с экскаватором, погрузчиком и автокраном. Панорама оставляет спокойное пространство слева и целую технику справа. Для мобильного экрана создан отдельный исходник с экскаватором и погрузчиком. Изображение на телефоне расположено между действиями и общими контактными данными: кнопки не закрывают машины.

Это иллюстрации, созданные встроенным Imagegen по разрешению владельца. Они не подтверждают состав автопарка и не заменяют фотографии конкретных машин в каталоге. Исходные PNG находятся в `docs/references/rental-hero-*.png`; точные промпты, SHA-256 и параметры WebP — в `docs/rental-hero-image-sources.json`. В WebP записано XMP-происхождение; Impeccable сохраняет точный промпт в соседних `.webp.json`. Воспроизводимая подготовка: `node tools/prepare-rental-hero.js`.

`rental-hero.css` содержит только оформление первого экрана и включается в `rental-critical.css` через `extraSources`. Общий `internal.css` не увеличивается, дополнительного запроса CSS нет. При изменении этого слоя сначала собрать сайт, затем пересобрать critical CSS и снова выполнить `npm run verify`. Шрифты, тексты, CTA и остальной каталог сохранены.

Direction contract: Persuade, узкая доработка существующего Industrial Editorial. Посетитель сразу видит узнаваемую технику целиком; desktop использует панораму, mobile — свободную область между действиями и фактами. Система сайта, реальные фотографии каталога и достоверные условия аренды остаются источниками правды. Новый кадр — декоративная иллюстрация, а не доказательство наличия конкретных машин.

- Финальный Lighthouse всех 12 новых маршрутов: Performance 98–99, Accessibility/Best Practices/SEO 100, LCP 2,103–2,404 с, CLS 0. Порог 95 и лимит LCP 2,5 с не изменялись. Главная и ремонтный эталон отдельно получили 98/100/100/100.
- Первоначальное превышение LCP hub устранено уменьшением первого HTML-ответа: аренда содержит только используемые symbol из общего SVG-спрайта. Категории получают облегчённые 640×400 превью; подробные фотографии машин сохранены. Сборка проверяет, что каждая используемая пиктограмма осталась в HTML.
- Независимое текстовое ревью: замечания закрыты (`Approved`). Визуальное ревью Impeccable: `ship`; отдельная проверка оптимизированных фото не обнаружила визуальных регрессий.
- Detector Impeccable работал в regex fallback: вычисленный контраст он не оценивал; его рекомендации по размеру шрифта не заменяют принятый дизайн-контракт. Доступность отдельно проверена Lighthouse.
