# Страница О компании

Маршрут `/o-kompanii/` относится к семейству `company` и описывает РемСД как организацию. Данные находятся в `src/data/internal-pages/o-kompanii.json`, композиция — в `company-page.html`, стили — в `company-page.css`. Страница не использует `repair-v1` или `brand-v1`.

## Содержание

Восемь блоков: первый экран с реальным фото, цифры, три этапа развития без календарных дат, ремонтная база, специализации команды, принципы сотрудничества, официальные марки и документы, контакты с картой. Источники — согласованный владельцем план, текущая конфигурация РемСД, `remsd.ru` и раздел вакансий. Цифры используют уже принятые значения 10+, 500+, 23 марки и работу без выходных. Люди на фотографиях не привязаны к именам.

Материалы компании: [главная remsd.ru](https://remsd.ru/) и [специализации в вакансиях](https://remsd.ru/vakancii). Фотографии и документы повторно используют существующие WebP проекта без изменения изображений; точные адреса исходников на Tilda записаны в `tools/prepare-media.js`. История написана как три этапа без календарных дат по согласованному плану владельца.

Тексты, фотографии, показатели и состав документов меняются через данные страницы. Контакты и график поступают из `site-config.json`. Телефонные CTA расположены в hero и завершении; форма заявки не добавляется.

## Медиа и навигация

Фото и документы открываются в нативном `dialog`, поддерживающем Escape, стрелки, кнопки переключения и возврат фокуса. Ссылки на изображения остаются пригодными без JavaScript. Все шесть листов сертификата соответствия входят в одну группу. Карту загружает IntersectionObserver при приближении к контактам; адрес и ссылка на маршрут видны независимо от iframe.

В общем меню «О компании» находится после аренды. Ссылка есть в футере и блоке базы главной. На 1121–1280 px метаданные шапки скрываются, телефон остаётся справа; burger включается на прежних 1120 px. Прозрачная область перехода к выпадающему меню сохраняется.

## Сборка и SEO

`company.css` использует общие tokens, foundation, site chrome и свой композиционный слой. `company-critical.css` включает hero и цифры; генератор учитывает новый размер 1280 px для промежуточного состояния шапки. Font-face остаются в critical CSS без повторной регистрации в отложенном бандле. Обе языковые части шрифтов предварительно загружаются.

JSON-LD: `AboutPage`, `BreadcrumbList`, `Organization`, `LocalBusiness`/`AutoRepair`. Для компании не создаётся сущность `Service`. Preview сохраняет noindex; production получает canonical и запись в sitemap.

## Проверки

`npm run verify`, `npm run test:browser`, `npm run test:lighthouse`, `git diff --check`. Для адресного браузерного прогона можно задать `BROWSER_ROUTES=o-kompanii`, для Lighthouse — `LIGHTHOUSE_ROUTES=o-kompanii` на production-like сборке.

Проверяются базовые ширины 320–1992 px и дополнительная 1121 px, тип страницы, восемь блоков, активный пункт меню, две телефонные кнопки, размеры изображений, отсутствие переполнений, просмотр многостраничных документов, Escape и возврат фокуса. Общие тесты проверяют главную и страницы ремонта после расширения меню.

Адресная проверка от 24.09.2026: браузер — 12 ширин; Lighthouse — Performance 99, Accessibility 100, Best Practices 100, SEO 100, CLS 0. Независимый визуальный просмотр подтвердил desktop/mobile, уточнение названия сертификата УРАЛ, показатель «7 / дней в неделю» на 320 px и загруженную карту. Итоговый вердикт по списку исправлений — ship.
