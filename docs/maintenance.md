Обновление Actions и фиксация runner-image остаются отдельной инфраструктурной задачей с адресной проверкой, не новым полным UI-прогоном без причины.

## Что и где менять

| Изменение | Единственный источник |
| --- | --- |
| Текст отдельной страницы, title/description, фото и FAQ | JSON страницы из src/data/internal-pages/index.json |
| Телефон мастера, почта, адрес, график | src/data/site-config.json |
| Общие этапы, показатели, марки и контакт FAQ ремонта | src/data/page-templates.json |
| Параметры машин и тарифы аренды | src/data/rental-catalog.json |
| Телефоны отделов, реквизиты, карта контактов | src/data/contact-details.json |
| Сканы, назначения и даты документов | src/data/documents.json |
| Общие цвета, шрифты, направляющая | assets/css/design-system.css |
| Шапка, меню, футер, кнопки и callbar | общие partials + assets/css/site-chrome.css |

Word и Markdown владельца — источники редакции, не зависимости сборки. После переноса рабочий текст хранится в JSON. Главная сохраняет свои содержательные partials; общие контакты также подставляются из конфигурации. Подтверждённые тексты не переписываются ради нового шаблона.

Не редактировать dist вручную: он пересобирается. Не копировать общие блоки в JSON отдельных страниц. Разные семейства имеют свои композиции; унификация касается компонентов, фактов и токенов, а не одинакового количества секций.

## Проверки

Для правки текста: verify и адресная проверка изменённого блока. Для модулей данных: дополнительно test:maintenance. Для инфраструктуры: check:syntax и тесты выбора CI. Полные browser/Lighthouse остаются для системных изменений; прошедшие проверки без новой причины не повторяются.

Этап доводки использует сохранённый контрольный dist, сравнение девяти представительных поверхностей на 1440/390px с допуском 1px и один итоговый полный CI. Схема v3 и PageDefinition не менялись. Фото, контент и metadata сохраняются; production 404 отдельно получает noindex.

Локально прошли 28 maintenance-контрактов, 13 правил выбора CI, syntax для 54 JS, production/preview verify и строгий check:release всех 56 содержательных маршрутов. Все 57 HTML сверены с исходной сборкой вне разрешённых CSS, версии ресурсов и эквивалентного экранирования карты. Девять поверхностей проверены на 1440/390px, включая совпадение фокуса общей оболочки, Escape/стрелку и цели меню. Совместимость Lighthouse 13 проверена адресно на контактах: 100/100/100/100, LCP 1881ms, CLS 0; полный выпускной прогон остаётся CI.

Локальная правка .agent/agents/remsd-copywriter.md не входит в выпуск.

Финальный Impeccable detector на пяти представительных HTML повторил исходный набор эвристик: статические оценки мелких меток, glow, палитры/радиусов, а также две записи о скрытых изображениях просмотрщиков без стартового src. Новых подтверждённых дефектов не выявлено; эти сообщения не подавлялись новыми ignore-правилами и не использовались для изменения утверждённого дизайна. Формат старого sidecar сохранён, его фактические описания обновлены без миграции инструмента.
