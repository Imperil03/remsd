# V3 handoff, 2026-05-26

## Current state

`/v3/` is the active experimental homepage for the next REMSD main page. The current public homepage `/` is intentionally kept on the old shared blocks. Most new work is isolated in v3 partials and `assets/css/styles-v3.css`.

The current branch is:

```bash
codex/v3-truck-brands-grid
```

Open locally after build:

```text
dist/v3/index.html
```

Or through a local static server:

```bash
python -m http.server 4173 --directory dist --bind 127.0.0.1
```

Then open:

```text
http://127.0.0.1:4173/v3/
```

## How to continue from another computer

```bash
git clone https://github.com/Imperil03/remsd.git
cd remsd
git checkout codex/v3-truck-brands-grid
npm install
node tools/build.js
```

If PowerShell blocks the npm shim, run the build through Node directly:

```powershell
node tools/build.js
```

## What changed in this iteration

- Reworked `/v3/` as a separate page structure in `src/pages/index-v3.html`.
- Added v3-only lower-page blocks: `v3-service-base`, `v3-repair-services`, `v3-company-proof`, `v3-contact`, `v3-footer`.
- Reworked the truck brand block into a dark section with a scannable logo grid. KAMAZ, MAZ and URAL stay first as official service brands.
- Reworked the equipment category block with large photo cards and clearer client-facing text.
- Reworked special equipment cards: removed narrow descriptions under each item and softened hover behavior.
- Replaced the old shared repair-services block on `/v3/` with a new informational service catalog without links to non-existing service pages.
- Replaced the old bottom area with a proof block about the repair base, a contact block, and a v3-only footer.
- Added mobile-only quick anchors after the hero: `Тип техники`, `Марка`, `Услуги`, `Контакты`.
- Changed the shared mobile bottom CTA text to `Позвонить мастеру`.
- Added and optimized new WebP assets for brands, service illustrations and v3 structure cards.

## What still needs manual review

1. Mobile first pass:
   - 360 px, 390 px, 414 px and 768 px widths.
   - No horizontal scroll.
   - Mobile quick anchors jump to the right sections and leave comfortable top spacing.
   - Bottom CTA shows `Позвонить мастеру` and does not cover important content at the bottom.

2. Hero:
   - H1 and CTA are readable on phones.
   - The next section is visible enough after the first viewport.
   - Header menu and callbar do not compete for attention.

3. Equipment categories:
   - Photos are understandable for each category.
   - "Окраска грузовой техники" does not visually fall out of the set.
   - Text on cards fits without awkward breaks on mobile.

4. Truck brands:
   - 2-column mobile grid is not too long visually.
   - Logos are large enough and not blurry.
   - Official KAMAZ, MAZ and URAL cards look stronger, but not like a separate unrelated block.
   - Future brand links currently point to prototype URLs like `/remont/{slug}/`; before moving this to `/`, either create these pages or disable unfinished links.

5. Service catalog:
   - 9 cards are readable on mobile without feeling too heavy.
   - Blue micro-accent matches the rest of the page better than the previous red.
   - Lists are useful and not overloaded.

6. Repair base proof block:
   - Main photo and small photos create trust and do not look too dark.
   - Proof list looks like evidence, not buttons.
   - All 10 certificates open in the lightbox.
   - Certificate strip is not too visually heavy on phones.

7. Contact block and footer:
   - Phone link works.
   - `Открыть в Яндекс Картах` opens the route/map.
   - Footer links point only to existing pages.
   - Footer text is readable and useful for organizations.

8. Desktop/tablet regression:
   - `/v3/` still looks balanced on 1366, 1440 and tablet widths.
   - Current public `/` does not receive v3-only blocks.
   - Shared mobile callbar text change is acceptable for `/` too.
