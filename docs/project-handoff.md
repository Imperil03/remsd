# Project Handoff

Дата: 2026-05-27

## Что это за проект

РемСД — статический сайт сервисного центра по ремонту грузовых автомобилей и спецтехники в Сургуте. Продакшен-превью собирается в `dist/` и публикуется через GitHub Pages.

Главные направления:
- главная продвигает общий локальный интент: грузовое СТО, грузовой автосервис, ремонт грузовых автомобилей и спецтехники в Сургуте;
- официальный сервис КАМАЗ, МАЗ, УРАЛ как proof-сигнал и отдельный брендовый слой;
- будущая SEO-структура строится вокруг типа техники, типа спецтехники и марки грузовика;
- ремонт агрегатов и систем остается support-контентом и внутренней перелинковкой, но не top-level навигацией;
- аренда спецтехники как отдельное направление, не смешивать с ремонтом.

## Актуальная главная

Бывшая v3-версия перенесена в production-главную `/`. Отдельные `/v2/` и `/v3/` удалены.

Главная находится в `src/pages/index.html` и собирается из:
- `v3-hero` — полноэкранный industrial hero с SEO-H1, CTA звонка и proof-line;
- `v3-tech-categories` — категории техники сразу после hero;
- `v3-truck-brands` — КАМАЗ, МАЗ, УРАЛ кликабельны как существующие страницы, остальные марки показаны как placeholder-ссылки `href="#"` с будущим URL в `data-future-href`;
- `v3-service-base` — промежуточный блок про грузовой автосервис;
- `v3-special-equipment` — типы спецтехники как будущие направления с placeholder-ссылками `href="#"`;
- `v3-repair-services` — ремонт по узлам и системам;
- `v3-company-proof` — база, реальные фото и сертификаты;
- `v3-contact` — сценарий передачи техники в ремонт;
- `v3-footer` и `mobile-callbar`.

Shared partials для внутренних страниц сохранены: `header`, `main-nav`, `footer`, `mobile-callbar`, `base-gallery`, `certificates-gallery`, `media-lightbox`, `home-structured-data`.

## Навигация

Верхнее меню использует единый partial `main-nav` на главной и внутренних страницах. Top-level пункты: `Ремонт`, `Аренда техники`, `Сертификаты`, `Контакты`, телефон.

Актуальные правки шапки:
- логотип заменен на кириллический `assets/img/logo-remsd.png`;
- в шапке добавлены NAP-элементы: `Сургут, Домостроителей, 13` и `info@remsd.ru`;
- на мобильных адрес, email и верхний телефон скрываются, потому что основной звонок остается в нижней CTA-плашке;
- если шапка покажется перегруженной, сначала убрать блоки `.v3-header__meta` и `.header-meta`, а не перестраивать всю навигацию.

`Ремонт` раскрывает mega-menu по трем слоям: тип техники, тип спецтехники, марки грузовиков. `Ремонтная база` не выводится в top-level, потому что этот интент поддерживает главную. `Узлы и системы` не выводятся в mega-menu: они остаются информационным блоком главной и support-страницами.

Текущее состояние dropdown:
- промо-карточка `Ремонт` содержит кикер, заголовок, короткий текст, CTA и фото; плашки `Сургут` и `КАМАЗ / МАЗ / УРАЛ` удалены;
- в группе `Марки грузовиков` не писать отдельный заголовок `Официальный сервис` и не возвращать синюю вертикальную линию;
- официальный статус КАМАЗ, МАЗ и УРАЛ передан компактными маркерами и `aria-label`;
- `Аренда техники` использует отдельную промо-карточку с фото автокрана и текстом `Спецтехника для объекта`.

## Сборка

`tools/build.js` теперь собирает только production-вывод:
- копирует `assets/` в `dist/assets/`;
- рендерит `src/pages/**/*.html`;
- поддерживает вложенные partials, чтобы `main-nav` можно было использовать внутри `header` и `v3-hero`;
- генерирует существующие SEO-страницы из `src/data/seo-pages.json`;
- не создает `/v2/` и `/v3/`.

Команды проверки:

```bash
node tools/build.js
git diff --check
```

`dist/` отслеживается в git, поэтому после сборки коммитятся и исходники, и обновленный `dist/`.

## SEO-правила

Актуальная карта лежит в `.agent/SEO_STRUCTURE.md`.

На текущем этапе не создавать новые страницы категорий, брендов и типов спецтехники без отдельного решения. Будущие пункты меню и карточки на главной показываются как placeholder-ссылки `href="#"`; реальный будущий URL хранится в `data-future-href`, а переход блокируется JS, чтобы не было 404 и прыжка страницы вверх.

Не создавать тонкие страницы формата `услуга x марка`, например `/remont-gbc-kamaz/`, без фактического контента, показов/кликов или отдельного решения.

## Документация и agent-контекст

- `AGENTS.md` — быстрый входной контекст.
- `.agent/SEO_STRUCTURE.md` — SEO-архитектура и запреты.
- `.agent/agents/` — роли копирайтера и ревьюера.
- `docs/design-guideline.md` — визуальные правила.
- `docs/skills.md` — поясняет, что vendored skills больше не хранятся в репозитории.

Не восстанавливать удаленные `.agent/CONTENT_GUIDE.md`, `.agent/CLAIMS_LEDGER.md` и `.agent/skills/` без отдельного запроса.

## Как продолжить с другого компьютера

```bash
git clone https://github.com/Imperil03/remsd.git
cd remsd
npm install
node tools/build.js
```

Готовая главная после сборки:

```text
dist/index.html
```

Локальный сервер для визуальной проверки:

```bash
python -m http.server 4173 --directory dist --bind 127.0.0.1
```

Открыть:

```text
http://127.0.0.1:4173/
```
