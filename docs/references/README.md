# Visual References

## `internal-hub-block-reference.png`

Исходный внешний референс, переданный владельцем 29.08.2026 для страницы «Ремонт грузовых автомобилей».

Что из него утверждено:

- порядок смысловых разделов;
- спокойное карточное оформление услуг, техники, признаков и этапов;
- светлые таблицы цен, связанные направления и FAQ;
- общая логика расположения текста и изображений внутри блоков.

Что не переносится:

- плотность и малые межсекционные отступы;
- чужой логотип, цветовая система, реквизиты и изображения;
- формы и частые промежуточные CTA;
- любые факты, которых нет в подтверждённых данных РемСД.

Бренд и уровень воздуха задаёт утверждённая главная РемСД. Текущая реализация сочетания этих источников находится на `/remont-gruzovyh-avtomobiley/`.
