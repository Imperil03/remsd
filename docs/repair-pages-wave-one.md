## Контракт authoring → PageDefinition

- Manifest `src/data/internal-pages/index.json` сохраняет schemaVersion 3 и referenceByFamily.hub.
- У шести исходников стоит необязательное `template: "repair-v1"`.
- `tools/lib/page-templates.js` загружает `src/data/page-templates.json`, создаёт независимую копию и подставляет общие поля до `validatePageDefinition`.
- На выходе обычный полный PageDefinition без поля template. Ни renderer, ни HTML-каркас не зависят от сокращённой формы.
- Порядок по умолчанию: introProof → serviceGrid → popularWorks → vehicleTypes → brandShowcase → editorialContent → symptoms → workStages → priceExamples → relatedIndex → faq.
- Единственный источник общих данных: hero.facts, introProof.stats, весь контент brandShowcase, workStages.items, faq.contact. Копии этих полей в исходниках запрещены — даже если значения совпадают. Неизвестный шаблон, неправильный порядок или override вызывают понятную ошибку.
- Заголовок этапов может быть тематическим. Остальные тематические поля, изображения, CTA, цены, ответы FAQ и closingCta остаются данными страницы.
- Страницы без template свободны в композиции. Сокращённый service fixture валидируется и рендерится, но не публикуется.
- Новых типов секций, зависимостей, фреймворков и публичной версии схемы нет.

Lighthouse теперь запускается через тот же bundled Chromium headless shell, что и браузерные тесты; настройки защиты компьютера не изменялись. Используется локальный debug-порт 4176, при необходимости задаваемый LIGHTHOUSE_CHROME_PORT. Это изменение тестового окружения, не публичного CSS/JS или ограничений качества.

Первый CI-проход обнаружил переполнение длинного слова в описании связанной карточки на Linux при 1120 px. Для всего текста карточки добавлен overflow-wrap как запасной вариант для слова, которое целиком не помещается по ширине. Автоматические переносы остаются только у заголовков: включение их для всех описаний меняло высоту уже утверждённого эталона. Кегль, сетка и запрет разрывов заголовков этапов сохранены. Отдельный тест проверяет карточки при 1120 px без словаря переносов.
