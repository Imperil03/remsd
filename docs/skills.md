# Project Skills

Vendored Codex skills больше не хранятся в репозитории РемСД. Ранее добавленные `.agent/skills/` удалены как внешний vendor-контекст, чтобы не раздувать проект и не смешивать продуктовый исходный код со справочными материалами.

## Приоритет Правил

1. Системные и developer-инструкции текущей Codex-сессии.
2. `AGENTS.md`.
3. `.agent/SEO_STRUCTURE.md`.
4. Существующий контент сайта, сертификаты/документы в проекте и явно указанные пользователем источники фактов.
5. `.agent/agents/` для роли копирайтера и ревьюера.
6. Общие skills Codex из локального окружения, если они доступны в текущей сессии.

Любой внешний skill носит рекомендательный характер. Он не должен перебивать B2B-стиль РемСД, SEO-структуру, факты проекта и запрет на фейковые цены, сроки, гарантии, рейтинги, отзывы и манипулятивную срочность.

## Работа С Текстом

Для публичного русского текста:

1. Проверить `.agent/SEO_STRUCTURE.md`.
2. Сверить факты с существующим контентом сайта, документами в проекте и явно указанными источниками.
3. Писать спокойно и конкретно: без рекламных штампов, неподтвержденных цифр и обещаний.
4. Для крупных SEO/коммерческих текстов использовать `.agent/agents/remsd-copywriter.md`, затем `.agent/agents/remsd-reviewer.md`.

Подтверждённые владельцем документы и обязательства сервиса можно формулировать прямо: договор, заказ-наряд, согласование сметы, срока и дополнительных работ, акт выполненных работ и гарантийные документы. Ограничение относится к выдуманным условиям и цифрам, а не к самой коммерческой конкретике.

## Работа С Дизайном

Опираться на `docs/design-guideline.md`, `docs/design-system.md` и `DESIGN.md`: промышленный B2B, реальные фото, содержательно собранная структура, заметный межсекционный воздух, редкий CTA звонка, доступная мобильная версия и единый кодовый контракт. Для эталонного hub композиционный референс хранится в `docs/references/internal-hub-block-reference.png`; копировать из него плотность, брендинг и реквизиты нельзя. Визуальные эксперименты допустимы только если они помогают коммерческой задаче и не создают фейковые claims.
