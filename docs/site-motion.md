# Анимации сайта — 02.10.2026

Impeccable animate сохраняет Industrial Editorial и режим каждой страницы. Движение показывает результат действия и связь между элементами; первый экран, текст и статические карточки не получают анимацию появления. Контакты сохраняют отдельно утверждённое подтверждение копирования.

## Что изменено

- Галереи главной, компании и документов: выбранное изображение раскрывается из превью за 350 мс и возвращается за 180 мс. Масштаб равномерный; фотографии учитывают crop/cover, документы показываются целиком через contain. При переключении кадра используется короткое движение 8 px. На границе списка повторного эффекта нет.
- Меню: появление за 180 мс и затухание за 120 мс. Закрытие `hidden`, `inert`, `aria-expanded` и возврат фокуса происходят сразу. Для затухания используется временная недоступная для ввода копия без ID и data-привязок. Контекст `.v3-nav` сохраняет цвет ссылок.
- FAQ: нативный `details` меняет состояние сразу; ответы раскрываются, соседние строки перемещаются через FLIP за 260 мс. При закрытии короткая копия ответа затухает; высота элементов не анимируется. Без модуля или при reduced motion работает обычный native details.
- Ссылки и реальные карточки: сохраняют существующий hover/focus, получают общие timings; стрелки связанных разделов смещаются на 3 px. Статические элементы не становятся интерактивными. Мобильная callbar использует прежние условия появления и быстрый токен 180 мс.
- Якорные переходы: целевой H2 получает янтарный маркер 64 × 2 px. На контактах остаётся прежняя реализация, без двойного эффекта.

## Код и ограничения

`assets/js/site-motion.js` — небольшой собственный модуль, подключённый перед main.js через общий footer. `window.REMSDMotion` содержит внутренние средства анимации и отмены; типы страниц, manifest и схема не меняются. Контроллеры main.js и company.js сохраняют поведение и получают вызовы этих средств. Дополнительных библиотек, изображений, шрифтов или публичных текстов нет.

CSS-файлы и все семь бандлов совпадают с предыдущим выпуском. Существующие semantic-токены используются для цвета и обратной связи; inline-геометрия временных копий измеряется при действии. Internal CSS остаётся 71 519 bytes при лимите 70 KiB. Critical CSS не меняется: исходные CSS и состав первого экрана прежние.

В обычном состоянии контент видим. Анимация не задерживает работу кнопки, открытие/закрытие диалога и нативные состояния. Ресурс ждут не более 300 мс только для эффекта; поздняя загрузка показывается без него. Таймаут снимается после успешной загрузки. Изменение reduced motion, скрытие вкладки, resize и изменение scroll отменяют незавершённые эффекты; копии удаляются. Маркер якоря сохраняет смысл во время прокрутки. Циклов и постоянных will-change нет.

Reduced motion оставляет значения состояний и статический маркер без WAAPI-последовательностей. Если файл или API анимации недоступны, штатные ссылки, меню, FAQ и галереи продолжают работать.
